# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — start the Vite dev server
- `npm run build` — production build (output to `dist/`)
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint

No test suite exists in this repo.

**Note:** `eslint.config.js` ignores `src` (`{ ignores: ['dist','src'] }`), so `npm run lint` currently does not actually lint any application code — keep this in mind if lint passes silently after edits.

## Environment variables

`src/pages/Contacts.jsx` reads EmailJS credentials via Vite env vars: `VITE_APP_EMAILJS_SERVICE_ID`, `VITE_APP_EMAILJS_TEMPLATE_ID`, `VITE_APP_EMAILJS_PUBLIC_KEY`. These must be supplied in a local `.env` file (not checked into the repo) for the Contact form to send mail in dev/build.

## Architecture

This is a single-page 3D portfolio built with React + Vite, React Three Fiber (`@react-three/fiber`/`drei`), Tailwind CSS, and `react-router-dom`.

- **Routing**: `src/App.jsx` wraps everything in a `BrowserRouter` with `NavBar` always rendered and four routes (`/`, `/about`, `/Projects`, `/Contact`) mapped to `src/pages/*`, re-exported through `src/pages/index.js`.
- **3D models**: `src/Models/*.jsx` are GLTF components auto-generated by `gltfjsx` from `.glb` assets in `src/assets/3d/`. Each wraps a `useGLTF`-loaded scene in a `<group>`/`<a.group>` and exposes props for position/scale/rotation plus any animation/interaction state. When regenerating a model from a new `.glb`, prefer re-running gltfjsx over hand-editing node names.
- **Home page (`src/pages/Home.jsx`)** composes the main 3D scene inside a single `<Canvas>`: `Island`, `Sky`, `Bird`, `Plane` models plus lighting. It computes responsive scale/position tuples for the island and plane based on `window.innerWidth` (mobile breakpoint 768px) and renders `HomeInfo` text that changes based on `currentStage`.
  - `Island` (`src/Models/island.jsx`) owns the interaction model: pointer drag / arrow-key rotation with damping (`rotationSpeed` decays by `dampingFactor` each frame via `useFrame`), and derives `currentStage` (1–4) from the island's normalized Y rotation angle. `setCurrentStage`/`setIsRotating` are lifted up to `Home` and drive `HomeInfo`'s copy and the cursor style.
  - Background music is a single `Audio` instance (`sakura.mp3`) held in a `useRef`, toggled by a mute/unmute icon button.
- **Contact page (`src/pages/Contacts.jsx`)** renders a form next to a `Fox` 3D model (`src/Models/Fox.jsx`) whose `currentAnimation` prop (`idle` / `walk` / `hit`) is driven by form focus/submit state and switched via `useAnimations` actions. Submission sends mail through `@emailjs/browser` using the `VITE_APP_EMAILJS_*` env vars above; success/error feedback goes through the `useAlert` hook (`src/Hooks/useAlert.js`) and `Components/alert.jsx`.
- **Constants (`src/constants/index.js`)** centralizes portfolio content data (`skills`, `experiences`, `socialLinks`, `projects`), each entry pulling its icon from `src/assets/icons/index.js` (a barrel re-exporting all SVG/PNG icon imports) or `src/assets/images/index.js`. Add new portfolio content by extending these arrays and adding the asset + barrel export.
- **Styling**: Tailwind, with custom theme extensions (colors, `worksans`/`poppins` font families, `card` box-shadow) in `tailwind.config.js`, plus component classes (`head-text`, `btn`, `input`, `textarea`, `blue-gradient_text`, etc.) defined in `src/index.css`.
- Vite is configured with `assetsInclude: ['**/*.glb']` (`vite.config.js`) so `.glb` files can be imported directly as asset URLs.
